# Bundled fonts

Manrope and DM Sans from https://github.com/google/fonts, under their included
SIL Open Font Licenses. These static instances were generated from the upstream
variable fonts using fontTools: Manrope weight 600; DM Sans weight 400, optical size
14. Internal font names are unchanged. Runtime aliases are Manrope and DMSans.
Fonts are bundled locally; no font network request is required at startup.
