# Contribution rules

- Put meaningful work on a focused feature or fix branch and open a pull request.
- Do not edit `main` directly, force-push, merge, or deploy without explicit authorization.
- Authored source and test files must be no more than 300 lines. Generated code, lockfiles, generated migrations, and external assets are exempt.
- Verify behavior with the relevant checks and report limitations honestly; never weaken assertions to hide an environment or implementation failure.
